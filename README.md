## Herramientas

 - Java
 - Maven
 - Git
 - GitHub
 - JUnit

## Estructura

 - `src/main/java`: código fuente.
 - `src/test/java`: pruebas.
 - `pom.xml`: configuración del proyecto Maven.

## Ejecución

Para compilar: `mvn clean compile`

Para ejecutar pruebas: `mvn test`
